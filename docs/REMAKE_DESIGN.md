## 1. 세계관 한 줄

노을 속 구름바다 위에 떠 있는 섬 요새 **에테르 보루**. 섬 끝에 선 거대한 수정 **마지막 빛(Last Light)**을 향해, 균열 포털에서 그림자 군세가 밀려온다.

## 2. 아트 방향

- **빛:** 골든아워 역광. 따뜻한 태양(주황~금색)과 차가운 하늘(보라~남색)의 보색 대비를 기본으로 삼는다. 하늘은 물리 기반 Sky 셰이더로 그리고, 그 하늘로 IBL을 구워 금속 반사에 쓴다.
- **재질 3층위:** 석재(무광·따뜻한 회색), 금장(고금속·반사), 수정(발광·블룸 대상). 발광은 수정·마법·이펙트에만 쓴다. 블룸은 이렇게 발광 요소에만 걸리게 해서, 레거시판처럼 화면 전체가 번지는 과노출을 막는다.
- **적은 흑요석 실루엣 + 발광 균열(보라/주황).** 밝은 초원 위에서 어두운 적이 가장 잘 읽힌다.
- **스케일:** 타워는 소켓 하나 크기. 전장과 경로가 화면의 주인공이다.
- **연출:** 운석, 연쇄 번개, 화염 폭발, 서리 파편처럼 화려한 이펙트는 짧고 굵게 터진다. 화면 흔들림, 동적 광원, 잔상을 쓴다.
- **판독성 원칙:** 사거리 링, 경로 흐름 표시, 공명 라인, 체력바는 어떤 연출보다 위에 그린다.

## 3. 게임 규칙

### 자원
- 골드: 처치 보상, 웨이브 클리어 보너스, 조기 호출 보너스로 번다.
- 생명: 수정 내구도 20. 일반 적은 1, 정예는 2, 보스는 10을 깎는다.

### 피해 유형
- **물리**(궁수탑·화염 박격포)는 `armor`만큼 감소한다.
- **마법**(서리 첨탑·폭풍 오벨리스크)은 `resist`만큼 감소한다.
- 조합을 섞을 이유를 만드는 핵심 장치다.

### 타워 (4종, 레벨 1→2→3, 이후 분기 A/B)
| 타워 | 유형 | 역할 | A 분기 | B 분기 |
| --- | --- | --- | --- | --- |
| 궁수탑 Ranger | 물리 | 빠른 단일 사격 | 저격수: 고피해·장사거리·방어 관통 | 일제 사격: 3표적 동시 |
| 화염 박격포 Ember | 물리 | 광역 폭발 | 용염: 불타는 지면(지속 피해) | 공성포: 피해·반경 대폭 |
| 서리 첨탑 Frost | 마법 | 광역 둔화 | 영구동토: 사거리 안 상시 둔화 오라 | 빙결 창: 둔화된 적에 큰 단일 피해 |
| 폭풍 오벨리스크 Storm | 마법 | 연쇄 번개 | 폭풍 군주: 연쇄 6회 | 과충전: 첫 표적 큰 피해 + 기절 |

### 공명 (인접 시너지)
맵마다 소켓 사이에 **레이 라인**이 정의돼 있다. 연결된 소켓에 **다른 종류** 타워가 서면 서로에게 버프를 준다. 버프는 타워 종류가 결정한다.

| 주는 타워 | 공명 효과 |
| --- | --- |
| 궁수탑 | 매의 눈: 사거리 +12% |
| 화염 박격포 | 열기: 피해 +15% |
| 서리 첨탑 | 취약: 둔화된 적에게 피해 +25% |
| 폭풍 오벨리스크 | 충전: 공격 속도 +15% |

### 액티브 스킬
- **유성 낙하**: 지정 지점 광역 화염 피해. 재사용 28초.
- **빙결 파동**: 전장의 모든 적을 2.5초 빙결. 재사용 50초.

### 웨이브
- 맵당 20웨이브이고, 웨이브는 맵 데이터에 손으로 짠다.
- 10번째 웨이브에 정예, 20번째 웨이브에 보스가 나온다.
- 다음 웨이브를 일찍 부르면 남은 대기 시간에 비례해 골드를 준다.

### 적
| 적 | 특징 |
| --- | --- |
| 그림자 병사 | 기본 |
| 추적자 | 빠름·약함 |
| 흑철 기사 | 느림·방어 높음 |
| 망령 | 마법 저항 높음 |
| 주술사 | 주변 아군 치유 |
| 공허의 거상 | 보스 |

### 결과
승리하면 남은 생명에 따라 별 1~3개를 받는다. 진행도는 localStorage에 저장한다.

## 4. 구조

```
index.html            Vite 진입점
src/
  core/               순수 로직(DOM·Three 없음, node:test로 검증)
    data/             towers, enemies, maps, waves 정의
    path.js           스플라인 샘플링과 거리 기반 위치
    game.js           상태 생성, step, 명령(build/upgrade/sell/skill/callWave)
  render/             Three.js 뷰(게임 상태를 읽기만 함)
    env/              하늘, 구름, 섬 지형, 도로, 소품, 포털, 수정
    models/           타워·적 절차적 모델
    fx/               파티클, 궤적, 번개, 투사체
  ui/                 HTML HUD, 방사형 메뉴, 화면(타이틀·맵 선택·결과)
  audio/              WebAudio 합성 효과음
tests/                core 단위 테스트와 헤드리스 밸런스 테스트
```

- **단방향 흐름:** 입력 → `core` 명령 → 상태 변경 → 이벤트 큐 → 렌더/오디오/UI 소비. 렌더는 로직을 바꾸지 않는다.
- **좌표:** 월드 단위 1 = 소켓 한 칸 정도. `core`는 (x, z) 평면만 알고, 높이는 렌더가 지형에서 샘플링한다.
- **품질 설정(상/중/하):** 픽셀 비율, 그림자 해상도, 블룸, 파티클 상한을 조절한다.
