# 프로젝트 상태: LAST LIGHT v2

2026-10-01 기준. 설계 근거는 [REMAKE_DESIGN.md](REMAKE_DESIGN.md)에 있습니다.

## 개요

- Vite + Three.js 0.184 기반 3D 타워 디펜스. 브라우저 전용, 서버 없음.
- 모든 에셋은 절차적입니다. 폰트만 `public/fonts`(Noto Sans KR)와 `@fontsource/cinzel`을 씁니다.
- 흐름: 타이틀 → 전장 선택 → 인트로 비행 → 전투 → 결과. 진행도(맵별 별 개수)와 설정은 localStorage `lastlight.v2`에 저장합니다.

## 규칙 요약

- **타워**: 궁수탑 70 · 화염 박격포 110 · 서리 첨탑 90 · 폭풍 오벨리스크 130. 레벨 3까지 강화한 뒤 A/B 분기를 고릅니다. 판매하면 투자액의 70%를 돌려받습니다.
- **공명**: 연결된 소켓의 다른 종류 타워가 주는 버프입니다. 같은 종류끼리는 버프가 없고, 종류별로 한 번만 적용됩니다.
- **피해**: 물리는 방어력(궁수 저격수는 70% 관통), 마법은 저항으로 줄어듭니다. 화상과 유성은 고정 피해입니다.
- **웨이브**: 웨이브 스폰이 끝나면 16초 카운트다운이 시작되고, 일찍 부르면 남은 초 × 1.5 골드를 받습니다.
- **체력 배율**: 웨이브마다 1.115배씩 오릅니다. 맵 배율은 서리 협곡 0.95, 공허의 첨탑 1.0이고, 웨이브 그룹별 `hpMul`로 따로 조정할 수 있습니다.
- **결과**: 남은 생명 90% 이상이면 별 3개, 50% 이상이면 2개, 그 밖은 1개입니다.

## 검증

- `npm test`: 22개 테스트. 맵 데이터 제약, 명령, 공명, 피해 유형, 웨이브 흐름, 스킬, 맵 3곳의 AI 밸런스를 검증합니다.
- 헤드리스 밸런스(자동 AI 기준):
  - 황혼의 성벽: 특화 8타워 전략이 생명 일부를 잃고 승리합니다.
  - 서리 협곡: 10타워 전략이 승리합니다.
  - 공허의 첨탑: 10타워 전략은 겨우 이기고, 6타워 전략은 집니다.
- 성능 참고치 (1600×900, 16웨이브, 적 37·파티클 1.4k): 시뮬레이션 0.2ms, 뷰 갱신 1.6ms, 렌더 약 11.5ms.
