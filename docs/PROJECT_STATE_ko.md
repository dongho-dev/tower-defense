# 프로젝트 상태: LAST LIGHT v2

2026-10-01 기준. 설계 근거는 [REMAKE_DESIGN.md](REMAKE_DESIGN.md)에 있습니다.

## 개요

- Vite + Three.js 0.184 기반 3D 타워 디펜스. 브라우저 전용, 서버 없음.
- 모든 에셋은 절차적입니다. 폰트만 `public/fonts`(Noto Sans KR)와 `@fontsource/cinzel`을 씁니다.
- 흐름: 타이틀 → 전장 선택(난이도·모드) → 인트로 비행 → 전투 → 결과. 승리하면 끝없는 밤으로 이어 갈 수 있습니다.
- 모드: 전투(20웨이브) · 끝없는 밤 · **공성전**(적이 타워를 부수고, 영웅과 병영으로 막는 RTS식 방어).
- 저장(localStorage `lastlight.v2`)
    - 기록 형식: `records[맵][키] = { stars, best }`
        - 키는 난이도(`easy`/`normal`/`hero`)입니다. 공성전 기록은 `siege-난이도` 키에 따로 둡니다.
        - `best`는 끝없는 밤 최고 웨이브입니다.
    - 그 밖의 항목: 본 적(`seen`, 도감), 설정, 마지막 난이도·모드(`lastMode`)

## 규칙 요약

### 타워 (7종)

| 타워            | 건설 비용 | 공명                          |
| --------------- | --------- | ----------------------------- |
| 궁수탑          | 70        | 사거리                        |
| 화염 박격포     | 110       | 피해                          |
| 서리 첨탑       | 90        | 둔화된 적 추가 피해           |
| 폭풍 오벨리스크 | 130       | 공격 속도                     |
| 비전 광선탑     | 120       | 방어·저항 무시                |
| 에테르 광산     | 100       | 처치 골드                     |
| 병영            | 80        | 협공: 붙잡힌 적에게 피해 +20% |

- **강화**
    - 레벨 3까지 올린 뒤 A/B 분기를 고릅니다.
    - 분기 뒤에는 각성 2단계가 있습니다. 단계마다 피해 +25%, 사거리 +5%, 광산 수입 +30%입니다.
    - 판매하면 투자액의 70%를 돌려받습니다. 판매 버튼은 두 번 눌러야 합니다.
- **병영**
    - 집결지(사거리 안 길 위, R 키나 패널 버튼으로 옮김)에 병사 2~3명을 세웁니다.
    - 병사는 지상 적을 붙잡아 멈추게 합니다. 비행 적과 보스는 붙잡지 못합니다.
    - 쓰러진 병사는 7~9초 뒤 부활합니다.
    - 분기
        - 성기사단: 받는 피해 -30%, 전투 중 회복
        - 검귀: 빠른 공격, 휩쓸기 50%
- **공명**: 연결된 소켓의 다른 종류 타워가 주는 버프입니다. 같은 종류끼리는 버프가 없고, 종류별로 한 번만 적용됩니다. 패널과 월드 화살표로 받는·주는 효과를 보여 줍니다.
- **피해**
    - 물리는 방어력, 마법은 저항으로 줄어듭니다.
    - 화상·유성·영웅 기술은 고정 피해입니다.
    - 특정 원인에 면역인 적이 있습니다(`takes`).

### 웨이브와 맵

- **웨이브**: 스폰이 끝나면 16초 카운트다운이 시작되고, 일찍 부르면 남은 초 × 1.5 골드를 받습니다.
- **체력 배율**: 웨이브마다 1.105배씩 오릅니다. 맵마다 `hpMul`이 있습니다.
- **맵 6곳**: 황혼의 성벽 · 서리 협곡 · 공허의 첨탑 · 잿불 고원 · 새벽 정원 · 폭풍 해안
    - 황혼의 성벽을 뺀 다섯 맵은 전용 적이 웨이브에 섞입니다(`THEMES`). 전용 적 수는 체력 합이 비슷하도록 맞춥니다.
    - 마지막 거상은 맵 보스로 바뀝니다. 거상이 둘이면 첫 거상만 바뀝니다.

| 맵          | 전용 적                                                            | 보스                   |
| ----------- | ------------------------------------------------------------------ | ---------------------- |
| 잿불 고원   | 잿불 자폭병(죽으면 주변 타워 기절), 불꽃 정령(화염 면역·폭발 절반) | 용암 군주(기절 파동)   |
| 서리 협곡   | 서리 갑주병(둔화·빙결 면역), 눈사태 거인(체력 절반 아래 분노)      | 빙하 거신(얼음 보호막) |
| 공허의 첨탑 | 그림자 도약자(순간이동), 분열체(죽으면 조각 둘)                    | 균열 군주(순간이동)    |
| 새벽 정원   | 꽃가루 정령(죽으며 주변 치유), 땅굴 두더지(잠복 중 공격 불가)      | 가시 고목(새싹 소환)   |
| 폭풍 해안   | 번개 흡수체(폭풍 탑 면역), 폭풍 하피(비행)                         | 폭풍 폭군(바람 장막)   |

- **보스 공통**
    - 빙결·기절을 30%만 받습니다.
    - 병사에게 붙잡히지 않습니다. 걸으면서 주변 유닛을 짓밟습니다.

### 모드·난이도·결과

- **공성전**
    - 적이 길가 타워에 공격을 날립니다. 사거리 2.1, 1.8초마다, 공격력 × 0.45 × 웨이브 배율입니다.
    - 체력이 다한 타워는 무너지고 소켓이 빕니다.
    - 수리: 비용은 잃은 체력 비율 × 투자액 × 35%입니다. 웨이브를 시작할 때마다 25%씩 저절로 회복합니다.
    - 적은 조금 약하고(체력 ×0.88) 시작 골드가 15% 많습니다.
    - 영웅 '새벽의 기사'
        - 조작: H로 고르고, 땅을 클릭하거나 우클릭해 이동합니다.
        - 근처 적을 붙잡아 싸웁니다. 처치 경험치로 최대 10레벨까지 오릅니다.
        - E '여명의 일격': 주변 피해와 기절. 재사용 대기 20초.
        - 쓰러지면 14초 뒤 수정 옆에서 부활합니다.
- **살아남기 '얼어붙은 분지'** (공성전 전용, 스타1 유즈맵 '살아남기' 방식)
    - 맵: 96×96 타일(1타일 1.2단위, 약 115×115). 설원 한 장이고 가장자리는 산맥으로 막힌다. 지형 격자는 `src/core/snowfield.js`, 정의는 `src/core/data/snowbasin.js`.
    - 지형 규칙
        - 높이는 이산적인 세 단(분지·벌판·고원)이다. 단 사이는 수직 바위 절벽이고, 윗변(통행 불가 테두리)은 회청색 띠로 칠한다.
        - 단을 바꾸는 길은 비탈뿐이다. 비탈은 축에 나란한 곧은 통로(폭 3~5칸, 길이 4칸)이고 양옆이 절벽 벽이라 위·아래 끝으로만 드나든다. 통로를 가로질러 벽 한 줄을 세우면 완전히 막힌다.
        - 고원 7곳(입구 1~3개). 입구가 많거나 둥지에 가까울수록 광맥이 많다(2~5개).
    - 시작: 맵 한가운데 둥지 곁에 생존자(일꾼) 한 명. 맵은 생존자 시야 말고 전부 검다. 밤 시계는 처음부터 흐르고 110초 뒤 둥지가 깨어난다. 930초(15분 30초) 버티면 승리.
    - 생존자
        - 우클릭: 이동(A* 길 찾기, 절벽을 돌아 비탈로). 다친·짓다 만 건물을 우클릭하면 가서 고치거나 마저 짓는다. Shift는 줄에 넣는다. C = 생존자로 카메라, Space = 본진.
        - 건설: B(본진, 맨 처음) · 1~7 → 고스트 → 클릭. 값은 주문할 때 치르고(취소·실패하면 돌려받음) 자리를 예약한다. 생존자가 그 자리로 걸어가 짓는 동안 비계와 진행률이 보인다. 방벽은 끌어서 줄로 예약하면 차례로 짓는다.
        - 싸우지 못하고 적이 노린다(곧은 걸음으로 닿는 땅 위의 적만, 하늘의 적은 건물만). 쓰러지면 15초 뒤 본진 곁에서 다시 일어나고, 본진이 없으면 패배.
        - 수리: 기존 수리비 셈(잃은 체력 비율 × 투자액 × 35%, 본진은 체력 1당 0.4)을 고치는 동안 조금씩 치른다.
    - 본진: 패배 조건이자 부활 지점. 정보 창에서 채굴 기술 3단계(150/300/500골드, 광산 수입 ×1.25/1.5/1.8).
    - 건설: 소켓 없이 탐험한 빈 땅 어디든 격자에 짓는다. 방벽 1×1, 타워 2×2, 광산 2×2(광맥 2×2에 꼭 맞게). 분지 둘레에는 못 짓는다. 건설 모드에서는 커서 둘레에 격자(초록 = 지을 곳, 붉은색 = 절벽·바위, 주황 = 비탈, 금빛 = 광맥)가 깔리고, 막힌 비탈에는 '봉쇄됨', 열린 비탈에는 '열림'이 뜬다.
    - 적: 둥지에서 나와 흐름장으로 가장 가까운 지킬 건물(본진·타워·광산)로 간다(건물이 없으면 생존자를 쫓는다). 방벽 칸은 부수는 비용(10 + 체력/45)을 더해 길을 고르므로, 막혔으면 벽부터 부순다. 하늘의 적은 벽을 넘는다. 6:30·10:30·14:30에 빙하 거신. 처치하면 현상금이 조금(×0.7) 들어온다.
    - 이동 규칙(적·생존자): 한 걸음에 이웃 칸으로만, 대각선은 양쪽 직교 칸이 모두 비어 있을 때만. 밀어내기(한 틱 최대 0.18)·도약도 같은 규칙을 지나고, 매 틱 끝에 막힌 칸에 선 몸은 마지막 바른 자리로 되돌린다.
    - 화면: RTS 카메라(가장자리·WASD·드래그·휠), 미니맵(탐험한 곳만, 보이는 적만, 생존자·예정 자리, 클릭 이동, 공격 경고 핑, 보스 경고), 탐험 안개(미탐험 검정·탐험했지만 시야 밖은 어둑하고 적은 숨김). 빙결 파동은 E.
    - 성능: 지형 메시는 12×12타일 조각으로 나눠 화면·그림자 카메라 밖 조각을 건너뛴다. 적·타워 모델의 움직이지 않는 조각은 재질마다 한 메시로 합치고(`src/render/survival/mergeEnemy.js`), 타워는 그림자를 드리우지 않는다(돌 기단이 드리운다). 적이 45마리를 넘으면 작은 장식을 감춘다.
    - 밸런스 조사: `node tests/survival-probe.mjs [고원들] [실험들]` (`tests/survivalAi.js`의 AI가 생존자를 움직인다).
- **결과**: 남은 생명 90% 이상이면 별 3개, 50% 이상이면 2개, 그 밖은 1개입니다.
- **난이도**: 쉬움(적 체력 80%, 시작 골드 +25%, 생명 30) · 보통 · 영웅(생명 1)
- **끝없는 밤**
    - 21웨이브부터 맵·번호로 결정되는 웨이브를 만듭니다. 맵 전용 적과 보스도 섞입니다.
    - 5웨이브마다 거상(맵 보스)이 옵니다.
    - 현상금은 21웨이브부터 웨이브당 4%씩 오릅니다.
- **정보 UI**
    - 웨이브 호출 버튼에 마우스를 올리면 다음 웨이브 상세가 나옵니다.
    - 처음 보는 적은 소개 카드로 알려 줍니다.
    - 도감은 맵별 군세로 나눠 보여 줍니다.
    - 적을 클릭하면 실시간 상태(보호막·장막·잠복·분노·붙잡힘)를 보여 줍니다.

## 검증

- `npm test`: 82개 테스트.
- 헤드리스 밸런스(자동 AI, 보통 난이도)
    - 전투
        - 모든 맵에서 8~10타워 전략이 이깁니다.
        - 공허의 첨탑은 6타워로 집니다.
        - 폭풍 해안 12타워(폭풍 탑 비중이 큼)는 번개 흡수체 때문에 집니다.
    - 난이도(10타워): 쉬움은 모든 맵 승리. 영웅은 세 맵 승리, 세 맵 패배.
    - 끝없는 밤: 골드 제한 없는 14타워 만렙 진영이 26~31웨이브에서 무너집니다.
    - 살아남기 '얼어붙은 분지'(생존자를 움직이는 AI, `node tests/survival-probe.mjs`)
        - 좋은 운영(가운데에서 출발 → 고원 탐험 → 본진 → 광산 → 비탈 방벽 두 줄 → 타워): 7곳 중 5곳 승리(북동·동·남동·남·서). 광맥 둘인 북서 벼랑과 입구 둘인 북쪽 눈마루는 마지막 대공세 즈음 무너진다.
        - 무대응(생존자만 서 있음): 모두 126초에 패배. 둥지가 깨어나면 생존자부터 쓰러진다.
        - 벽 없이 벌판에 본진·타워: 모두 패배(233~441초).
        - 고원 위 타워만(방벽 없음): 7곳 중 6곳 패배(남동 언덕만 승리).
        - 광산 없이: 모두 패배.
    - 공성전(수리만 하는 AI, 영웅은 가만히 둠)
        - 8타워 기본 전략은 6맵 모두 이깁니다.
        - 병영을 섞은 계획은 맵에 따라 승패가 갈립니다. 사람은 영웅 이동과 집결지로 더 잘할 수 있습니다.
- GPU 자원: 적·타워·유닛·이펙트를 지울 때 `src/render/dispose.js`로 geometry와 개체 전용 재질을 해제합니다. 모델 캐시가 나눠 쓰는 재질은 `markShared`로 표시해 건너뜁니다. 맵을 바꿀 때는 이전 장면 전체와 후처리 렌더 타깃을 해제합니다.
- 성능 참고치 (1600×900, 16웨이브, 적 37·파티클 1.4k): 시뮬레이션 0.2ms, 뷰 갱신 1.6ms, 렌더 약 11.5ms.
