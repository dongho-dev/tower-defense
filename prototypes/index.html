Q1 · 기존 코드를 어떻게 할까?

코드 전략이라 화면 데모 대신 비교표로 정리했어요.

선택지시작점속도리스크살릴 수 있는 것
A. 새로 설계 (둘 다 보관)
추천		깨끗한 모듈 구조로 시작초반은 느림낮음. 구조 부채가 없음이 데모의 sim 코어, 밸런스 수치, 맵 설계 아이디어, remake의 WebP 아트(2D일 때)
B. remake/ Last Light 발전1.9k줄 단일 파일, Canvas2D 전제빠름중간. 3D로 가면 렌더러를 전면 교체해야 함UI 레이아웃, 맵 3종, ImageGen 스프라이트 파이프라인
C. 루트 레거시 발전main.js 4.7k + three-scene.js 24.7k줄, 3.9k줄 미커밋느림높음. 블룸 과다·렌더러 이중 비용 등 구조적 문제GLB 생성 스크립트, 테스트 셋

어느 쪽을 고르든 레거시의 미커밋 변경(+3.9k줄, src/·assets/·scripts/)은 날아가지 않게 archive/legacy-3d 같은 브랜치에 먼저 커밋해 두는 걸 권합니다.

Q2 · 렌더링 방향

같은 맵, 같은 타워 11개, 같은 웨이브를 세 가지 방식으로 그렸어요. 나란히 번갈아 보면 차이가 가장 잘 보입니다.

Q2-AThree.js 저폴리 3D그림자, 동적 광원, 절제한 블룸. 드래그로 회전·줌 가능.추천 Q2-BCanvas2D 아이소메트릭remake/와 같은 계열의 2.5D. 가볍지만 카메라가 고정됨. Q2-C2D 탑다운 + 광원 연출판독성과 개발 속도가 최고. 네온, 블룸, 꼬리, 화면 흔들림.

Q3 · 게임성 범위

직접 플레이할 수 있어요. 숫자키로 타워를 고르고 클릭해 짓고, Space로 웨이브를 시작합니다. 타워를 클릭하면 업그레이드할 수 있어요.

Q3-A고정 소켓 + 분기 업그레이드정해진 자리에 짓고, 레벨 3에서 A/B 특화를 고름.추천 기반 Q3-B자유 배치 미로길이 없음. 타워와 벽으로 적의 최단 경로를 비틀기. Q3-C인접 시너지 + 액티브 스킬다른 종류끼리 붙이면 강해지고, 메테오와 오버클럭으로 직접 개입.추천 추가 요소 Q3-D로그라이크 카드웨이브마다 3장 중 1장을 골라 판마다 다른 빌드.

서로 배타적인 선택이 아니에요. 예를 들어 "A 기반에 C 추가, 엔드리스 모드에만 D" 같은 조합도 가능합니다.
