# LAST LIGHT — 에테르 보루

노을 속 구름바다 위에 떠 있는 섬 요새에서, 섬 끝의 거대한 수정 **마지막 빛**을 그림자 군세로부터 지키는 3D 타워 디펜스입니다. Three.js로 렌더링하고, 외부 이미지나 음원 없이 모든 모델·텍스처·효과음을 절차적으로 만듭니다.

## 특징

- **황혼의 아케인 판타지 톤**: 직접 설계한 노을 하늘 셰이더와 IBL, 셰이더로 그린 구름바다, 지층이 드러난 떠 있는 섬, 조약돌 도로와 등불, 성벽과 망루.
- **타워 7종 × 레벨 3 × 분기 2**: 궁수탑, 화염 박격포, 서리 첨탑, 폭풍 오벨리스크, 비전 광선탑, 에테르 광산, 병영. 레벨 3에서 특화를 고르고, 이후 각성 2단계까지 강화합니다. 살아남기에는 전용 방벽도 있습니다.
- **공명(인접 시너지)**: 레이 라인으로 연결된 소켓에 서로 다른 타워를 세우면 사거리, 피해, 공격 속도, 둔화 대상 추가 피해 버프를 주고받습니다.
- **피해 유형**: 물리 공격은 방어력, 마법 공격은 저항으로 줄어듭니다. 흑철 기사와 망령이 조합을 섞을 이유를 만듭니다.
- **액티브 스킬**: 유성 낙하(지정 광역), 빙결 파동(전체 빙결).
- **일반 전장 6곳**: 황혼의 성벽, 서리 협곡, 공허의 첨탑, 잿불 고원, 새벽 정원, 폭풍 해안. 20웨이브 전투와 끝없는 밤을 지원하며 맵별 전용 적과 보스가 등장합니다.
- **공성전 전용 전장 2곳**: 영웅·병영과 성문으로 막는 **성채 방어**, 일꾼 한 명으로 시작하는 **얼어붙은 분지**. 얼어붙은 분지에서는 검은 안개를 탐험하고 고원에 본진·광산·타워를 지어 15분 30초 동안 버팁니다.
- **조기 호출 보너스**: 다음 웨이브를 일찍 부르면 남은 시간만큼 골드를 받습니다.
- **연출**: 파티클, 연쇄 번개, 충격파, 폭발 광원, 유성 낙하, 빙결 껍질, 불타는 지면, 화면 흔들림. 블룸은 발광 요소에만 걸립니다.
- **UI**: 방사형 건설·업그레이드 메뉴, 수치 비교 카드, 사거리 표시, 체력바, 보스 체력, 웨이브 미리보기, 첫 플레이 안내, 별 3개 기록 저장.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 표시된 주소(기본 `http://localhost:5180`)를 엽니다. 배포용 빌드는 `npm run build`로 `dist/`에 만들어집니다.

URL 파라미터(개발용):

| 파라미터 | 효과 |
| --- | --- |
| `?play&map=frostvale` | 타이틀을 건너뛰고 바로 전투 시작 |
| `?demo&wave=16` | 타워를 미리 세우고 지정 웨이브부터 시작 |
| `?q=low` | 그래픽 품질 강제 (`high`/`medium`/`low`) |

## 조작

| 입력 | 동작 |
| --- | --- |
| 빈 소켓 클릭 | 건설 메뉴 (숫자키 1~7로 바로 건설) |
| 타워 클릭 | 업그레이드·분기(U / A·B)·판매(Delete)·조준 우선순위 |
| Space | 웨이브 호출 |
| Q / W | 유성 낙하 / 빙결 파동 |
| F | 배속 전환 |
| Esc | 메뉴 닫기, 일시정지 |
| 드래그·방향키 / 휠 | 시점 이동 / 확대·축소 |

살아남기에서는 조작이 바뀝니다. 우클릭으로 일꾼을 이동하거나 건설·수리를 지시하고, B로 본진을 짓습니다. 숫자키 1~7은 방벽·궁수탑·화염 박격포·서리 첨탑·폭풍 오벨리스크·비전 광선탑·광산 순서입니다. WASD는 카메라 이동, C는 일꾼 보기, Space는 본진 보기, Q/E는 유성 낙하/빙결 파동입니다. Shift를 누르면 명령을 대기열에 추가합니다.

## 개발

```bash
npm test          # 코어 단위 테스트 + 헤드리스 AI 밸런스 회귀 테스트
npm run lint
npm run format:check
node tests/balance-probe.mjs   # 맵별 밸런스 조사
node tools/place-sockets.mjs frostvale   # 소켓 배치 도우미
```

맵 경로와 소켓은 `tools/map-preview.html`(정적 서버로 열기)에서 확인할 수 있습니다.

## 구조

```
src/core/     게임 로직 (DOM·Three.js 의존 없음, node:test로 검증)
src/render/   Three.js 월드·모델·이펙트·카메라·후처리
src/ui/       HUD, 방사형 메뉴, 화면, 오버레이
src/audio/    WebAudio 합성 효과음
tests/        단위·밸런스 테스트
prototypes/   리메이크 방향을 정한 비교 데모
docs/         설계 문서와 프로젝트 상태
```

자세한 설계는 [docs/REMAKE_DESIGN.md](docs/REMAKE_DESIGN.md), 현재 상태는 [docs/PROJECT_STATE_ko.md](docs/PROJECT_STATE_ko.md)를 보세요.
